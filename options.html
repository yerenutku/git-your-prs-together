Per file: each file header in "Files changed" has an "Auto" switch left of GitHub's Viewed button. Turn it off to keep that one file from being ticked automatically. Remembered per PR.

Notifications

Desktop notifications from the same poll as the rest of the extension (every minute, with this browser's GitHub sign-in, or the token above). Each event notifies once; nothing old is replayed when you turn a type on. Missed one? The PR lists keep showing it: "N new comments" on your PRs, a count on "My threads" and "Re-review", until you open the PR.

Nothing pops up? In macOS System Settings → Notifications → your browser (e.g. Arc): "Allow notifications" on and the alert style set to Banners or Alerts. With "None" they only land in Notification Center.
